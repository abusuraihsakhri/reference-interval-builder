02 / OUTPUT

Analysis report

2.5% ↔ 97.5%

Ready for observations

Enter or import measurements to generate a reference interval estimate and confidence bounds. All computations take place in this browser.

Method: rank interpolation with normal-approximation binomial rank confidence limits; Tukey outlier screening and an exploratory Harris–Boyd pairwise screen.

Use limitation: descriptive research software, not a validated diagnostic device. CLSI recommends at least 120 suitable reference observations per partition for this approach. Outlier exclusion and partitioning require review.
